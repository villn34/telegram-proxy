# پروکسی SOCKS5 تلگرام — فرانکفورت (آلمان)

پروکسی SOCKS5 با proxy.py، بدون کارت بانکی، برای دیپلوی روی Render (ریجن Frankfurt) یا Railway.

## استفاده در تلگرام
Settings > Data and Storage > Proxy > Add Proxy > SOCKS5
- Server: آدرس سرویس Render/Railway
- Port: پورتی که سرویس می‌دهد
- Username/Password: خالی (بدون احراز هویت — فقط خودت استفاده کن)

## هشدار
- نسخه رایگان Render بعد از مدتی بی‌فعالیتی می‌خوابد؛ اولین اتصال چند ثانیه طول می‌کشد.
- این پروکسی بدون رمز است؛ لینکش را با کسی به اشتراک نگذار.
- IP سرور Render/Railway متعلق به همان سرویس است، نه لزوماً یک IP ثابت آلمانی.
